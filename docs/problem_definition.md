# problem definition

## 1. 문제 형태

본 과제는 절단 공정을 다음과 같이 단순화한 문제입니다.

- 여러 절단 설비가 동시에 존재
- 설비마다 가능한 작업 계열과 두께가 다름
- 설비마다 처리 속도가 다름
- 작업은 특정 후공정 베이로 이동
- 후공정 베이에는 우선순위와 적치 한계가 있음

따라서 문제는 `비관련 병렬기계 스케줄링`에 가깝습니다.

## 2. 현재 스켈레톤의 의사결정

현재 스켈레톤에서 한 step의 action은 아래와 같습니다.

- 작업 1개
- 설비 1개
- 즉, `(job, machine)` pair 1개 선택

## 3. 상태

현재 상태는 아래 정보로 요약됩니다.

- 현재 시각
- 남은 작업 목록
- 설비별 다음 가용 시각
- 설비별 누적 부하
- 후공정 베이별 적치량
- 현재 가능한 action 목록

## 4. 하드 제약

하드 제약을 만족하지 못하면 action 후보에서 제거됩니다.

- 설비 사용 가능 여부
- 작업 계열 호환
- 두께 범위
- 장비 길이 한계
- 동일 시점 단일 작업
- 일일 가용시간
- 후공정 적치 한계

## 5. 소프트 제약

소프트 제약은 위반해도 선택은 가능하지만 penalty가 붙습니다.

- 후공정 우선순위
- due date 긴급도
- 설비 선호 타입
- 적치 위험 경고
- 부하 평준화 선호

## 6. 목적

현재 reward는 아래 항목을 조합합니다.

- makespan 증가 최소화
- 설비 부하 편차 최소화
- 우선 작업 보너스
- soft penalty 최소화
