agent 후보 채택률 (per-Bay best-source, 이동평균)

agent 후보 64개 = agent_greedy 1 + agent_sample 63(_2~_64). 파란 선=agent 64종(greedy 포함) 전체가 teacher-best를 차지한 비율(= agent가 휴리스틱을 이긴 비율), 주황 선=그중 agent_greedy 단독 비율, 회색 선=휴리스틱이 이긴 비율(=100−파란). 후반 T↓로 회색이 줄고 주황이 오르면 greedy takeover.

in-dist MAIN validation best-rate (정식 지표 · Bay subproblem별 + overall, %)

학습분포 전용 validation(main). 학습분포(blocks 10-30, target-matching 없는 자연표본, held-out) 고정 grid의 각 Bay subproblem에서 proposed(best-of-K)가 1위인 비율. best checkpoint 선택 기준이 되는 지표. 본 run은 main-validation 도입 이전이라 저장 checkpoint를 사후 평가해 백필한 곡선(ep1000~20000).

generalization validation best-rate (일반화 테스트 · Bay subproblem별 + overall, %)

일반화 성능 테스트(리포팅 전용, best 선택에 미사용). 넓은 grid(blocks 10-100, distribution-type target-matched)의 각 Bay subproblem에서 proposed(best-of-K)가 1위인 비율. 학습분포(10-30)보다 크게 벗어난 문제를 포함하므로 위 in-dist MAIN보다 낮게 나오는 것이 정상.

학습 loss (teacher-imitation CE, 이동평균)

loss 절대값은 품질 지표가 아님. greedy가 teacher-best를 차지하기 시작하면 점프가 나타날 수 있음(정책이 뾰족해진 신호).
