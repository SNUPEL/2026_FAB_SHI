MIXED 합성데이터 인과 생성 최종 정리
작성일: 2026-07-16

1. 결론

전체 W/O 수는 기존 발표자료의 블록 수식을 그대로 사용한다.
계열별 생성기가 각자 W/O 수를 만든 뒤 합치는 방식은 폐기했다.
현재 유일한 생성 순서는 다음과 같다.

물리 블록 목표 특성
-> 물리 블록 전체 WO_QTY
-> 계열 조합
-> 계열별 WO_QTY
-> 계열별 W/O 특성
-> 생성 W/O의 block-series 역집계

NP-only는 계열 조합이 항상 NP 하나이고 N_NP=전체 WO_QTY였던 특수 사례다.
MIXED는 같은 순서에서 계열 조합과 계열별 정수 배분 단계만 추가한다.

2. 물리 블록 전체 W/O 수

물리 블록 LTH, MARK_LTH, CUT_LTH와 전체 WO_QTY는
Utils/data/report_formula_data_generator.py의 기존 발표자료 고정식으로 먼저 생성한다.

WO_QTY = max(
    1,
    round((0.01203 * CUT_LTH + 2.014) * Gamma(shape=7.616, scale=0.128))
)

이 값은 이후 계열 조합이나 계열별 생성기의 관측 지원값에 맞춰 변경하지 않는다.
FORMULA_WO_QTY, 계열별 SERIES_WO_QTY 합, 실제 물리 블록 W/O 행 수는 항상 같아야 한다.

3. 계열 조합 생성

실적 기준 물리 블록은 1,044개이며 NP/FN/FL/NC의 계열 조합은 13종이다.
전체 WO_QTY보다 계열 수가 많은 조합과 계열별 생성 지원범위로 배분할 수 없는 조합은
선택할 수 없다. 가능한 조합만 남긴 뒤 실적 조합 확률을 재정규화해 하나를 표본화한다.

따라서 모든 물리 블록에 네 계열이 생기지 않는다.
한 episode 전체에 FN, FL 또는 NC가 하나도 없을 수도 있다.
계열별 독립 Bernoulli 추출이나 W/O별 무작위 계열 부여는 하지 않는다.

4. 계열별 W/O 수 배분

선택한 계열 조합 안에서 생성 물리 블록의 LTH, THK, CUT_LTH, 전체 WO_QTY rank와
가까운 실적 물리 블록 8개를 찾는다. 거리 역수 확률로 조건부 count vector profile
하나를 선택한다. 이 8-neighbor 규칙은 현재 명시된 모델 계약이며 fallback이 아니다.

실적 count vector 비율에 가장 가까운 양의 정수 벡터를 계산하되 다음을 강제한다.

- 선택된 계열의 W/O 수는 각각 1 이상이다.
- 선택되지 않은 계열의 W/O 수는 0이다.
- N_NP + N_FN + N_FL + N_NC = 물리 블록 전체 WO_QTY다.
- FN/FL/NC는 해당 empirical 생성기에서 관측된 계열별 최대 W/O 수를 넘지 않는다.
- NP가 포함된 조합에서는 NP가 원 수식 총합을 만족시키는 잔여 수를 수용할 수 있다.
- 배분 불가능하면 다른 값으로 대체하지 않고 원인을 출력한 뒤 실패한다.

5. 계열별 W/O 특성 생성

계열별 W/O 수를 확정한 뒤 각 생성기에 prescribed WO_QTY를 입력한다.

- NP: 발표자료 고정식과 고정 오차분포를 사용한다.
- FN/FL/NC: 같은 empirical 생성 흐름을 사용하되 계열별 계수, 잔차분포, 지원범위를 사용한다.
- BTH: 공통 로그선형식 구조에 계열별 계수, 잔차, 관측 규격을 사용한다.
- STL_QTY: WO_QTY와 별도인 계열별 조건부 정수 분포로 생성한다.
- TACT_TIME: 전 계열에 발표자료 Case 6 공통식을 사용한다.

TACT_TIME = 0.3037 * CUT_LTH
          + 0.1325 * MARK_LTH
          + 0.4790 * THK
          + 0.3840 * PTLST_QTY

같은 물리 블록의 계열은 공통 physical seed에서 파생한 서로 다른 결정론적 난수
stream을 사용한다. 계열마다 동일 난수열을 재사용해 가짜 완전상관을 만들지 않는다.

6. W/O에서 block-series로 역집계

최종 block-series key는 (PROJ_NO, BLK_NO, GYEL)이다.

최댓값 집계:
- LTH
- BTH
- THK
- MARK_LTH
- TACT_TIME

합계 집계:
- CUT_LTH
- BVL_LTH
- STL_QTY
- BV_QTY
- PTLST_QTY

행 수 집계:
- WO_QTY = 해당 block-series의 W/O 행 수

WO_QTY와 STL_QTY는 서로 다른 변수다.
WO_QTY는 W/O 행 수이고 STL_QTY는 W/O STL_QTY의 합이다.

7. 제거한 잘못된 방식

다음 방식은 현재 실행 경로에서 사용하지 않는다.

- 계열별 W/O 수를 서로 독립 생성한 뒤 합산
- 임의 비율로 전체 W/O 수를 계열별 분할
- 실적 지원값에 맞춰 원 수식 WO_QTY를 스냅
- 생성 후 block swap
- 생성 후 계열 교환
- Hungarian 최소비용 사후 매칭
- 상관계수를 맞추기 위한 생성값 재배치
- 컬럼 누락, 식 실패, 배분 실패의 silent fallback

8. Phase 1과 Phase 2 연결

Phase 1과 Phase 2는 Utils/data/multi_series_formula_data_generator.py의 동일한 공용
episode 생성기를 사용한다. 같은 seed와 물리 블록 수를 주면 wo_df, block_df, jobs와
W/O identity가 정확히 같아야 한다. episode는 미리 파일 1,000개를 만들어 저장하지
않고 학습 episode마다 메모리에서 생성한다.

9. strict validation

생성기는 반환 전에 다음을 모두 검사한다.

- 물리 블록 수
- 계열 조합
- block-series 중복 없음
- W/O identity 중복 없음
- FORMULA_WO_QTY = TOTAL_WO_QTY
- 계열별 배분 수 = 실제 계열별 W/O 행 수
- 계열별 배분 합 = 원 수식 전체 WO_QTY
- 원 수식 전체 WO_QTY = 실제 물리 블록 W/O 행 수
- 필수 특성 결측 없음
- 양수/비음수 범위
- W/O 역집계 block-series와 출력 block_df의 완전 일치

하나라도 다르면 정상 결과를 반환하지 않고 오류를 출력한 뒤 예외를 발생시킨다.

10. seed 20260716 검증 결과

- 실적 물리 블록: 1,044개
- 생성 물리 블록: 1,044개
- 생성 series-block: 1,610개
- 생성 W/O: 9,221개
- 계열 조합분포 총변동거리: 0.034483
- 최대 계열 조합 비율 오차: 1.8199%p
- 계열 간 상관관계 수: 216개
- 계열 간 상관 MAE: 0.278174

생성 W/O 9,221개는 실적 11,646행을 복제한 값이 아니다. 1,044개 합성 물리 블록에
기존 발표자료 전체 WO_QTY 수식을 적용한 합계다.

사후 Hungarian 매칭을 제거했기 때문에 과거 비인과 구현의 상관 MAE 0.151084보다
현재 MAE가 크다. 현재 결과는 인과 순서, 조합분포, W/O 수 identity를 우선 보장한다.
희소 계열 쌍의 모든 상관관계를 완전 재현한다고 주장하지 않는다.

14. 최종 질문에 대한 답

그렇다. 물리 블록의 전체 WO_QTY는 기존 발표자료 원 수식으로 먼저 생성된다.
계열 조합과 count vector는 그 정수를 나누기만 하며, 전체 WO_QTY를 다시 뽑거나
실적 지원값으로 바꾸지 않는다.
