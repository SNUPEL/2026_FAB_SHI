# 회의 사항

- **W/O**
    - 스케줄 있음 → 공정별 절단 착수일
    - 하루에 절단하는 W/O의 숫자 확인 필요
- **판넬 스케줄 최적화 현황**
    - 최적화 모델과 현장 사이의 괴리(?) 발생
    - 제약이 줄어들고 목적함수가 많아져서 더 문제
    - 강화학습 모델 수정 정리해서 5월 말 검증 예정
- **절단 스케줄 최적화 소개(Bay 2~4는 소조 중조 대조 전용)**
    - 절단 공정 레이아웃(PLS: 플라즈마, NCG:~~가스,  LSR: 레이저, LM: 크레인)

        ![image.png](attachment:912b207d-0809-4f96-82d3-d509a5edb8b2:image.png)

        - **Bay 1: 소부재 전용(과제 대상은 아님)**
        - Bay 2: (신)PLS 4대, LM 3대
        - Bay 3: (신)PLS 3대, NCG 1대 → **NCG - LSR(26년)** , LM 2대
        - Bay 4: PLS 4대 → **LSR 3대(26년)**, LM 2대
        - Bay 5: PLS 2대→**LSR 2대(26년)**, LM 2대 ← 이것도 판넬 전용이라고 보면 됨
        - **Bay 6: (신)PLS 2대, LM 2대, 판넬 전용**
    - 최적화 방안
        - 절단 후공정: 판넬 → 소조 → 중조 → 대조 (3주 스케줄 송부)
            - 운영반: W/O 기반 Bay별 물량 배정(주간 스케줄)
                - 제약/목적함수
                    - Bay별 설비능력
                    - 계열/제원
                    - Bay별 부하 평준화
                    - 후공정 일정
                    - 블록 모둠단위
            - Bay별: 설비 부하 기반 일일 스케줄
                - 제약/목적함수
                    - 左同(좌동?)
                    - 배원
                    - 설비 고장/수리
                    - 우선순위
                    - 설비별 정반 제약
            - 필요성 → **설비 부하 평준화를 고려한 통합 스케줄 최적화**
                - 설비 능력 및 레이아웃 변경에 따른 대응 필요
                    - 24H 공급 체계 구축 → 암묵지 기반 스케줄 어려움
                - 주 일 단위 분할된 계획 통합 관리로 성력화
                    - 운영반 주간 계획 수립 - 베이별 일일 계획 수립 → 동기화 X
                - 실행 환경 변동성에 대응 어려움
                    - 일일 배원, 설비 고장, 후공정 일정 변경 할때 고려 요
                - 공정간 대기 Loss 증가 대응 방안 필요
                    - 공정 단위 설비 투자로 능력 편차 증대 → 선별/ 적치 이슈
    - 절단 공정 주요 제약
        - 설비 제약: 설비 별 작업 가능 계열 및 크기 제약 상이
            - 설비 타입: NP/FN/FL/NC(gas)///FT/ST
            - 현재 기준 플라즈마 설비 기준(1. main / 2. 선호 / 3. 비선호 / 4. 과부하시 어쩔 수 없이)
                - 플라즈마가 과부하일때는 NC(가스)로 하기도 함
            - 26년 8월 이후 레이저 도입 기준
                - (제약) LSR: 20T 이하
                - (목적함수) PLS: 20T 초과
            - 광폭 가능 설비: 설비 라인 별 폭 정보 정의 중
        - 베이 제약: 계열 별 제작 가능 베이 제약(물량에 따른 변동)
            - 현재 설비 기준 베이-계열 제약
            - 레이저 투자 기준 베이-계열 제약
            - FT 계열은 T-bar 등 형강 물량 → 확장 가능
        - 정반 제약: 설비 및 베이별 작업장 조건에 따라 정반 타입 상이**(현재 삼성은 대부분 고정정반)**
            - 고정 정반: 사이즈 제약 X, 전체 라인 길이 제약? 컨 차이?
            - 컨베이어 정반: 정반 사이즈 제약 X, 전체 라인 길이 제약?
            - 회전 정반: 정해진 규격의 정반이 회전하는 방식
            - → 회전 정반 제외 검토 중, 광폭만 고려하면 됨
            - **고정, 컨베이어만 과제범위 일듯(?)**
        - 기타 제약
            - 블록셋 제약
                - 블록 단위 W/O는 동일 베이 할당 (선별 반출 용이)
            - 크레인 제약
                - 크레인 당 이동 시간 정의 → 베이 별 선별 시간 반영
                - 크레인에 대한 과부하가 있을수도 있으니까…
        - 목적함수: 부하 평준화(상세히 검토하시진 않음 → 변경 될 수도), 절단기의 가동률 편차 줄이기, makespan은 고려 필요 없을듯?
            - 베이 별 부하 평준화
            - 설비 별 부하 평준화
            - 계열 등 물성 우선순위
    - 데이터 제공
        - W/O 데이터 : 삼성에서 쿼리 개발 중 → 블록 단위로 구성
        - 택트타임 정보 : 산출 로직 + 절단 실적 데이터 함께 송부 예정
            - 네스팅: 고정시간(크레인에 따른 고정시간으로 가정) ←배재를 네스팅이라 칭함(?)
            - 절단: 절단장에 따른 산출 로직 및 실적 데이터
            - 선별: 크레인 이동 시간 및 후처리 시간으로 구성
        - 설비 및 작업장 정보: 작업장 별 설비 및 정반 길이, 크레인 대수
